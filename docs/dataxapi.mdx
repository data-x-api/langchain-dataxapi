This guide provides a quick overview for getting started with the DataXAPI [tools](/oss/langchain/tools). DataXAPI serves public social media and market data from Douyin, Xiaohongshu (RedNote), WeChat Official Accounts, WeChat Channels, WeChat Search, Weibo, Bilibili, Zhihu, Kuaishou, Douyin's trend index, TikTok, YouTube, X and Reddit through one API key. For every endpoint, its parameters and price, head to the [DataXAPI endpoint reference](https://dataxapi.com/apis/?ref=langchain).

### Features

- **Find any endpoint for free:** `DataXAPIFind` takes a need in plain words, in English or Chinese, and returns the matching endpoints with price, required parameters and example parameters. It needs no API key.
- **Call any of the 237 endpoints:** `DataXAPICall` calls an endpoint by its ID with its parameters as an object.
- **Typed tools for the most used endpoints:** twelve tools, each with its own argument schema and allowed values, generated from DataXAPI's catalog.
- **No sign-in to a platform account:** no cookies or QR login.
- **Pay per call; errors are not charged.** Each tool's description states its price, and every answer says what the call cost.
- **Sync and async:** every tool supports `invoke` and `ainvoke`.

## Setup

To access the DataXAPI tools, you'll need to create a DataXAPI account, get an API key, and install the `langchain-dataxapi` integration package. New accounts get a free trial of up to 333 calls, with no card.

### Credentials

Create a key in the [DataXAPI console](https://dataxapi.com/console/keys/?ref=langchain). It starts with `dx_`.

```python Set API key icon="key"
import getpass
import os

if "DATAXAPI_API_KEY" not in os.environ:
    os.environ["DATAXAPI_API_KEY"] = getpass.getpass("Enter your DataXAPI API key: ")
```

It's also helpful (but not needed) to set up LangSmith for best-in-class observability/<Tooltip tip="Log each step of a model's execution to debug and improve it">tracing</Tooltip> of your tool calls. To enable automated tracing, set your [LangSmith](/langsmith/observability) API key:

```python Enable tracing icon="flask"
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

### Installation

The DataXAPI tools live in the `langchain-dataxapi` package:

## Instantiation

Instantiate one tool, or get all of them from the toolkit:

```python Initialize tool instance icon="robot"
from langchain_dataxapi import DataXAPIToolkit, DataXAPIXiaohongshuNoteSearch

tool = DataXAPIXiaohongshuNoteSearch()

tools = DataXAPIToolkit().get_tools()
```

`DataXAPIToolkit(endpoint_tools=False)` gives only `dataxapi_find` and `dataxapi_call`, which reach every endpoint with a shorter tool list.

## Invocation

### Directly

`DataXAPIXiaohongshuNoteSearch` takes `query` (required), and optionally `sort` (`relevance`, `latest`, `popular`, `most_comments` or `most_favorites`), `type` (`video` or `image`), `published_within` (`day`, `week` or `half_year`) and `cursor` for the next page.

```python Call tool icon="rocket"
tool.invoke({"query": "露营", "sort": "popular"})
```

```json
{
  "endpoint": "xiaohongshu.notes.search",
  "data": {"items": [{"id": "…", "url": "…", "title": "…", "author": {"name": "…"}, "metrics": {"likes": 48, "comments": 21}}]},
  "page": {"next_cursor": "…", "has_more": true},
  "billing": {"amount": "0.02", "currency": "USD", "balance_after": "9.98"},
  "request_id": "…"
}
```

### As a ToolCall

We can also invoke the tool with a model-generated `ToolCall`, in which case a @[`ToolMessage`] will be returned:

```python ToolCall icon="briefcase"
# This is usually generated by a model, but we'll create a tool call directly for demo purposes.
model_generated_tool_call = {
    "args": {"query": "露营", "sort": "popular"},
    "id": "1",
    "name": tool.name,
    "type": "tool_call",
}
tool.invoke(model_generated_tool_call)
```

### Within an agent

We can use the toolkit in an agent. For this we will need a model with tool-calling capabilities.

```python Agent with tool icon="robot"
# pip install -qU "langchain[anthropic]" to call the model
from langchain.agents import create_agent

agent = create_agent(
    model="claude-sonnet-4-6",
    tools=DataXAPIToolkit().get_tools(),
)

# Run the agent
agent.invoke(
    {
        "messages": [
            {
                "role": "user",
                "content": "What do people on Xiaohongshu and Douyin say about camping coffee gear this week? "
                "Pick the three most liked posts and summarize their top comments.",
            }
        ]
    }
)
```

## Find and call any endpoint

For data without a named tool, an agent describes the need to `dataxapi_find` (free) and calls the endpoint it returns with `dataxapi_call`:

```python Find and call icon="search"
from langchain_dataxapi import DataXAPICall, DataXAPIFind

DataXAPIFind().invoke({"query": "bilibili user profile"})

DataXAPICall().invoke({"endpoint": "bilibili.users.get", "params": {"id": "8047632"}})
```

## Pages and errors

One call returns one page. For the next, call again with `cursor` set to the last answer's `page.next_cursor`; each page is charged on its own.

An error comes back as the tool's answer, naming the error code, whether anything was charged and whether to retry, so an agent can correct itself. Pass `handle_tool_error=False` to raise `ToolException` instead.
